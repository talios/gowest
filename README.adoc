= Gowest

== Introduction
Gowest is an opinionated, and simple Continuous Build tool
written in the Google Go language and targeted specifically
at the Gerrit Code Review tool.

Gowest monitors Gerrit stream events for newly upladed
patch sets and then clones/builds the project as requested.

== Building

[source]
----
go get
go build
----

== Configuration

Gowest reads `gowest.ini` from the working directory. The `[gowest]` section supports:

`workspace`:: Directory the projects are checked out and built in.
`clearVerificationLabel`:: When `true`, vote Verified -1 as a build starts, clearing any
earlier verdict until the build finishes. Defaults to `false`, which leaves the Verified vote
unchanged until the build's result is posted.

[source,ini]
----
[gowest]
workspace=/tmp/gowest
clearVerificationLabel=false
----
